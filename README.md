# 分鏡指令選擇器｜AI Storyboard Prompt Selector & 3D Previz

一個專為 **AI 影片生成（Seedance、即夢、Runway、Kling 等）** 設計的視覺化分鏡指令編輯器與鏡頭表工作台。  
透過點選電影語言卡片（景別、機位、運鏡、焦段、構圖、光線、色調、表演、聲音設計）即時組裝中英文提示詞，並搭配 **3D 灰模站位預演與動作解析**，在生成影片前先把人物站位、朝向與運鏡錄成參考影片，大幅降低 AI 生成時的人物漂移與畫面崩壞。

> **Zero-Backend & Privacy-First**：純前端靜態網頁（HTML/JS/CSS），無需後端伺服器或登入帳號。所有上傳圖片、鏡頭表與預演／生成影片皆僅儲存在你本機瀏覽器的 `IndexedDB` 與 `localStorage`，不會上傳至任何外部伺服器。

---

## 核心功能 Core Features

1. **視覺化分鏡指令組合器（Prompt Builder）**
   - 內建 SVG 示意圖卡片：景別、機位角度、運鏡、焦段／景深、構圖、光線、色調、微表演、身體動作、分層聲音設計（環境底聲／擬音／特殊音效／配樂／人聲／聲畫銜接）與禁止事項。
   - **動作負荷與崩壞風險即時評估**：自動偵測高風險組合（如「運鏡＋大幅度身體動作」「多人過肩鏡無足夠角色」）並提供拆分建議。
   - **三格式同步產出**：`結構化`、`單段中文`、`English` 一鍵切換與複製，並支援手動微調。

2. **3D 站位預演與自然語言動作解析（3D Blocking Previz）**
   - 內建 Three.js 3D 灰模預演舞台，支援 1～4 位角色（含四足寵物模型）與 8 種場景灰模（街道、咖啡廳／餐廳、車廂、門口、走廊、辦公室、浴室、客廳）。
   - **畫面內容補充自動解析**：輸入如 `主角 A 把咖啡杯遞給主角 B` 或 `主角 A 難過地坐在咖啡廳桌前，喝了一口`，即自動拆解場景、姿勢、情緒、道具與動作時序；亦可於介面手動覆蓋調整。
   - **雙人互動自動取景**：擁抱、遞物、搶奪、推開等互動動作會自動計算整段動作邊界，確保兩位角色全程留在畫面內。

3. **預演影片錄製（WebM / MP4 Export）**
   - 直接於瀏覽器內錄製 3D 站位預演（含鏡號、焦段與時間碼 HUD），下載後可作為 AI 影片生成工具的「參考視頻」。

4. **通用素材庫 ＋ 本機自訂圖片上傳（Custom Assets）**
   - 開箱即用內建通用預設素材（主角 A、主角 B、配角／長輩、朋友、貓咪／寵物、4 種常見場景、4 種常見道具），100% 內嵌向量圖示無破圖。
   - 支援「**＋ 新增自訂素材**」：點擊選檔或拖放 `PNG / JPG / WebP`，自動壓縮並持久化儲存於瀏覽器 `IndexedDB`，可依點擊順序自動編號 `@圖片1`、`@圖片2`、支援 Lightbox 放大檢視與單筆刪除。

5. **多集數鏡頭表與卡片式分鏡審閱板（`shots.html`）**
   - **多集數管理**：建立、切換、複製、重新命名與刪除不同集數（例如 `EP01`、`EP02`），每集獨立保存集數簡介、審閱須知筆記、分鏡圖、3D 預演與生成影片版本；支援匯出／匯入本集 JSON 備份。
   - **雙檢視模式一鍵切換**：支援「📋 表格檢視」與對標審閱頁的「🎬 分鏡審閱板（卡片式）」，包含頂部集數摘要統計（鏡數、累計時碼、分鏡圖／預演／生成數、檢收進度）、審閱須知區塊、Sticky 鏡號快速跳轉導覽列、分鏡圖上傳／貼上（存於 IndexedDB）、**3D 預演 ⇄ 生成影片同步播放對比**、以及可收合的中文指令／English prompt 複製按鈕。
   - **一鍵匯出成果**：支援 **Excel（`.xlsx`）** 報表匯出，以及 **匯出單頁審閱 HTML**（將分鏡圖、預演縮圖、指令與筆記打包為獨立靜態網頁，方便團隊直接開啟審閱）。

## 如何使用 How to Use

### 方式一：GitHub Pages 線上直接使用（最推薦）

無需下載或安裝任何軟體，直接在瀏覽器開啟已部署的 GitHub Pages 網址即可使用。  
所有資料仍保存在你自己的瀏覽器本機空間內，不同使用者之間資料完全隔離。

### 方式二：下載 ZIP 本機執行（一鍵啟動）

1. 點擊 GitHub 頁面右上角 **Code → Download ZIP** 並解壓縮（或 `git clone`）。
2. 依作業系統雙擊啟動檔：
   - **Windows**：雙擊 `啟動選擇器.bat`
   - **macOS / Linux**：雙擊 `start.command`（macOS 首次執行若提示安全性，請右鍵 →「打開」；Linux 請先確認檔案具備執行權限 `chmod +x start.command`）
3. 啟動腳本會自動於 `127.0.0.1` 尋找可用連接埠（預設優先 `8765`，確保每次開啟使用同一組本機儲存空間），並自動在瀏覽器開啟 `index.html`。

> **為什麼不建議直接雙擊 `index.html`（`file://` 協定）？**  
> 現代瀏覽器對 `file://` 本機路徑有嚴格的安全隔離限制，直接雙擊可能會導致：
> - `index.html` 與 `shots.html` 無法正常共用 `localStorage` 與 `IndexedDB`（新增的鏡頭或自訂圖片在另一頁看不到）。
> - 部分瀏覽器限制 `file://` 下的 `MediaRecorder` 錄影、跨頁同步與剪貼簿複製功能。  
> 因此請務必透過 **GitHub Pages（HTTPS）** 或 **一鍵啟動檔（`http://127.0.0.1`）** 開啟。

## 自訂角色／場景圖片與資料儲存說明

### 如何新增自訂素材
1. 在 `index.html` 展開 **「00+ 素材庫資產」** 區塊，點擊右上角 **「＋ 新增自訂素材」**。
2. 點擊選檔或將圖片（`PNG` / `JPG` / `WebP`）直接拖放進上傳區。
3. 填寫 **資產名稱**（必填，此名稱亦會用於 3D 預演動作解析，例如填入「小美」後在畫面內容寫「小美拿起手機」即可自動對應）。
4. 選填 **英文關鍵詞**（留空時系統會自動依分類補上英文描述）、選擇 **分類**（角色 / 場景 / 道具）與 **狀態標籤**（如 `定稿`、`候選`、`自訂`）。
5. 點擊 **確認新增**，素材即會出現在對應分類中，可點擊選為 `@圖片1`、`@圖片2`、放大預覽或帶入 `shots.html` 鏡頭表。
6. **在 `shots.html` 鏡頭表頁直接補選／上傳參考素材**：無論在「表格檢視」或「分鏡審閱板（卡片式）」下，每鏡皆可在「參考素材資產」區塊點擊 **「＋ 加入／選擇素材」**，直接勾選內建預設或已上傳的自訂素材、或於彈窗內即時上傳新圖，確認套用後會自動更新該鏡的 `@圖片1`、`@圖片2` 編號與中英文指令。

### 本機資料儲存位置與備份建議
- **自訂上傳圖片**：壓縮後儲存於瀏覽器 `IndexedDB`（資料庫 `shotAssets` / store `assets`），不佔用 `localStorage` 5MB 配額。
- **預演影片與生成影片**：儲存於瀏覽器 `IndexedDB`（資料庫 `shotMedia` / store `files`）。
- **鏡頭表與指令文字**：儲存於瀏覽器 `localStorage`（鍵值 `shotLists_v3`）。
- **重要提醒**：資料完全留存在目前使用的瀏覽器本機；若清除瀏覽器快取／網站資料（Site Data）或更換瀏覽器，上述資料將會消失。重要專案請定期點擊 `shots.html` 的 **「匯出 Excel」** 備份指令與版本紀錄。

## GitHub Pages 部署教學

將本專案發布到自己的 GitHub Pages 只需 30 秒：

1. Fork 本專案，或建立新的 GitHub Repository 並上傳 `04-GitHub開源版` 內的所有檔案（`index.html` 須位於 Repository 根目錄，或你指定的發佈目錄）。
2. 前往 Repository 的 **Settings → Pages**。
3. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
4. Branch 選擇 **`main`**（資料夾選 **`/ (root)`**），點擊 **Save**。
5. 等待約 1 分鐘重新整理，即可透過 `https://<你的帳號>.github.io/<倉庫名稱>/` 直接使用。所有頁內連結與資源皆採相對路徑，支援任何子路徑部署。
